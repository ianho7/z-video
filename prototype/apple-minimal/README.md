# z-video Apple Minimal 线框探索

这是 z-video 的独立低保真结构探索。它只用灰阶、浅灰矩形和文字占位确认桌面片库的信息层级、导航关系和状态切换，不代表最终 Apple/macOS UI，也不代表最终 Rust + Slint 的控件样式、播放能力、性能或跨平台验收。

## 设计命题

一个安静、内容优先的片库浏览器：用户在固定的片库浏览画布里搜索、筛选和扫看片目，点选后进入同一窗口里的独立详情页。详情页不展开右侧面板，也不改变片库的列数；返回时恢复来源状态、搜索词、筛选条件和滚动位置。

本版本的签名是“稳定的浏览画布”：窗口基准为 1440×900，侧边栏约 220px，默认片库约 7 列海报占位。占位块只表达尺寸、分组、顺序和优先级，不能被误认为真实海报或视觉方向。

## 结构计划

```text
+----------------------+-----------------------------------------------+
| 侧边栏 220px         | 工具栏：当前视图标题       搜索       动作   |
|                      +-----------------------------------------------+
| 片库                 | 继续观看 / 最近添加 / 排序筛选结构占位      |
|   全部               |                                               |
|   电影               | 海报占位网格：1440×900 时约 7 列            |
|   剧集               | 标题、年份、类型占位                       |
| 浏览                 |                                               |
+----------------------+-----------------------------------------------+
```

- 侧边栏最多两级，提供隐藏入口；关键动作不会只放在侧边栏底部。
- 工具栏只放当前视图标题、搜索框和少量动作；搜索是主入口。
- 片库使用固定浏览画布；详情替换主内容区域，不与片库并排。
- 所有占位面、边框、文字和按钮使用黑白或浅灰阶。没有真实图片、影视素材、品牌资产、远程资源、渐变、阴影、玻璃效果或动画。
- `:focus-visible` 使用明确的黑色外框和文字提示，便于验证键盘路径；交互只用于验证结构，不模拟真实播放或 NAS 请求。

## 页面状态

### `?state=library`

默认片库。显示侧边栏、工具栏、继续观看或最近添加的横向结构占位、排序/筛选控件，以及约 7 列的海报占位网格。

### `?state=search`

搜索/筛选状态。显示搜索词、结果计数、条件占位、结果网格和清空/返回入口。示例：`index.html?state=search&q=关键词`。

### `?state=detail`

独立详情页。显示返回层级、主海报占位、标题/年份/类型、播放/继续播放、选集、简介和演员信息，优先级从上到下排列。打开详情时 URL 保留来源状态、搜索词、筛选条件和滚动位置；返回按钮、浏览器后退或 `Esc` 可回到来源片库。

## Apple/HIG 结构适配

本探索只借用适合 Windows first、未来 Rust + Slint 翻译的结构原则：清晰的侧边栏层级、轻量工具栏、标准集合网格、固定返回层级、可隐藏侧边栏、窗口可调整时的内容优先级，以及键盘焦点可见。参考了 Apple skill 的 accessibility、layout、typography、color、designing-for-macos、cross-platform、sidebars、toolbars、split-views、collections、searching、windows 和 focus-and-selection 资料。

低保真版本故意不表现 Apple/macOS 的窗口控制、系统图标素材、系统材质、品牌色和成品视觉质感；这些属于下一步高保真探索或最终 Slint 实现的决策。

## 验证边界与下一步

当前目录可直接双击 `index.html` 打开，或从仓库根目录启动任意静态文件服务器后访问该目录。页面不依赖构建工具、后端、字体、图片或网络。

本轮目标是确认三种页面状态的结构与返回关系。下一步才根据确认后的结构制作高保真方向，并分别在浏览器原型和 Rust + Slint 窗口中验证可用性；本线框不宣称最终性能、播放集成或 macOS 已运行。
