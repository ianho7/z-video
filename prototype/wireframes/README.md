# 片库桌面客户端低保真线框

这是一个独立的结构验证原型，不属于生产 UI，也不修改根目录的高保真 `prototype/` 原型。它只用灰阶矩形和文字占位，验证 1440 × 900 桌面窗口中的片库层级、密度和状态关系。

## 打开方式

直接双击 [index.html](./index.html)，或在浏览器地址栏打开这个文件。没有依赖、构建步骤或本地服务要求。

也可以用 URL 直接打开状态：

- `index.html?state=default`：默认片库，主内容区约 7 列。
- `index.html?state=detail`：独立详情页状态，片库内容暂时隐藏，详情使用完整内容区。
- `index.html?state=search`：搜索 / 筛选结果，包含输入、计数、条件和清空路径。

页面顶部的状态按钮可切换三种状态。点击海报卡片进入独立详情页；详情中的 `ESC`、顶部返回和页面内返回按钮回到进入详情前的片库状态。提交搜索会显示查询结果状态，清空搜索或返回片库会回到默认状态。

## 本轮修订

上一版把详情放在右侧抽屉中，导致片库列数、列表宽度和卡片位置跳动。本轮改为同一窗口内的独立详情页状态：片库始终保持固定约 7 列，详情使用完整内容区展示海报、标题、年份、类型、播放 / 继续播放、选集、简介和演员 / 导演。

进入详情时，URL 会保留 `from`、`query` 和 `scroll` 参数，例如 `state=detail&from=search&query=星际&scroll=240`。它们是低保真状态说明：返回片库时恢复进入详情前的片库状态、搜索词和网格位置；筛选条件用页面中的固定摘要表达。

## 本轮验证范围

- 左侧导航、顶部搜索、筛选排序、主内容区边界和海报墙层级。
- 默认 1440 × 900 约 7 列，进入详情时片库列数保持不变。
- 独立详情页的信息优先级、播放 / 继续播放、选集，以及 ESC / 返回路径。
- 搜索结果计数、条件状态、结果网格、清空和返回路径。
- 页面底部的状态关系说明。

这里没有接入真实 NAS 数据、登录、播放、进度写入、收藏、刮削或管理功能；影片标题、数量、年份和进度均为结构占位。
