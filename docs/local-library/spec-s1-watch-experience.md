# S1 Spec：观看标记与外观收口

Status: 已批准（2026-11-15），Ticket 21 / 22a / 22b。
词汇遵循 `GLOSSARY.md`：Marker、Media file、Source、Episode、Heat area。

## Problem Statement

看片时"这一段好"的位置没有任何记录手段，下次想回看只能凭记忆拖动进度条；同时界面上仍有系统原生控件（滚动条、折叠三角、悬浮提示），与整体视觉割裂，让人看得出这是"套壳"而不是一个完成品。

## Solution

- **Marker**：播放中一个按键记下当前位置，成为该 Media file 的时间点标记；关闭再打开仍在，并在进度条上可见、可跳转、可删除。标记只存在本机，永不写入媒体文件或 NFO。
- **外观收口**：滚动条、`summary` 折叠标记、悬浮提示改为应用内自绘，与现有配色和焦点样式一致。

## User Stories

1. 作为观看者，我想在播放中按一个键记下当前位置，这样不用暂停或离开画面就能标记"这里好"。
2. 作为观看者，我想让标记在重启应用后仍然存在，这样下次打开还能回到那一段。
3. 作为观看者，我想在进度条上看到自己打过的点，这样能一眼看出这部片我关心哪些区间。
4. 作为观看者，我想点击进度条上的标记直接跳过去，这样不用再手动拖。
5. 作为观看者，我想删除打错的标记，这样不用为了删一个点清掉整部片的进度。
6. 作为观看者，我想在没有任何标记时进度条保持干净，这样不会看到一排空刻度。
7. 作为观看者，我想在标记失败时得到明确反馈，这样不会以为已经记下了。
8. 作为隐私敏感的用户，我想标记只留在本机，这样它不会出现在任何导出、同步或网络请求里。
9. 作为使用快捷键的用户，我想打点不覆盖已有的静音键，这样现有习惯不被破坏。
10. 作为整理片库的用户，我想在删除 Source 时它的标记一并消失，这样不会留下孤儿数据。
11. 作为使用鼠标的用户，我想滚动条与应用配色一致，这样滚动区域不再像系统控件。
12. 作为使用折叠面板的用户，我想展开/收起标记是自绘的，这样不再出现系统三角。
13. 作为需要提示的用户，我想悬浮提示是应用内样式，这样不会弹出系统样式的黄色气泡。
14. 作为键盘用户，我想焦点环在自绘控件上仍然清晰可见，这样不用鼠标也能操作。

## Implementation Decisions

- schema v5 新增 `markers` 表，按 Media file 的 opaque `mediaId` 与秒级位置存储；每个文件可有多个标记；随 Media file / Source 删除级联清理。
- 新增 renderer-safe 契约：标记记录只含 `mediaId`、`positionSec`、`createdAtMs`，不含路径、标题或播放 URI。
- 新增按 `mediaId` 的列出 / 新增 / 删除通道，均在 main/worker 边界内校验 opaque id 与位置范围。
- 播放器快捷键：`B` 记录标记；`M` 保持静音，不改绑。
- 进度条渲染标记刻度；点击刻度跳转到该位置；删除在播放器内完成一次确认，不引入右键菜单系统。
- 无标记时不渲染刻度层，避免空白刻度造成的"有数据"错觉。
- 外观：自定义滚动条（含 hover 态）、`summary` 折叠标记替换、应用内 tooltip 取代原生 `title` 提示；不新增依赖。
- Marker 是用户手写的观察，不是内容质量结论；产品文案不得把它表述为"精华/最佳片段"。

## Testing Decisions

好的测试只验证外部行为：数据库 owner 的读写与级联、IPC 契约的拒绝/接受、播放器里按键后标记是否真的出现并可操作；不断言 CSS 的具体像素值或内部实现。

选用的缝（全部复用现有）：

- **Local library database owner 冒烟**（`test:local-library`）：标记的增删、重启保留、随 Source 删除、非法 mediaId 与越界位置被拒绝。
- **Player window 冒烟**（`test:player-window`）：真实播放器中按 `B` 记录、标记出现在进度条、点击跳转、删除后消失。
- **Window 冒烟**（`test:window`）：外观的结构性断言——不再依赖 `title` 原生提示、自绘 tooltip 节点存在、自绘滚动条样式生效。
- **自动化验收脚本**（`test:acceptance-window`）：如某条交互同时涉及 IPC 故障与 UI 反馈，可复用其故障注入设施。

像素级观感、DWM 采样与真实媒体播放仍属最终真机验收，不写成自动断言。

## Out of Scope

- Heat area（观看热度聚合）与音频波形。
- 自动生成标记、按弹幕/人群数据推断"精彩点"。
- 标记的导出、分享、云同步。
- 跨设备同步与账号体系。
- 视觉改版（配色、排版、布局重构）。

## Further Notes

- 标记是后续 Heat area 的数据来源之一；本 spec 只做记录与展示，不做聚合。
- 若未来要支持"多个标记合并为片段"，需要新的区间模型，不在本 spec 内。
- 外观收口不改变信息架构，只替换控件的呈现方式。
