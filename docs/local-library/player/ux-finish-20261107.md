# Local-library UX finish evidence (2026-11-07)

## Scope

This follow-up keeps the renderer/runtime fix and a short production-window proof in separate commits. It does not operate the user's desktop UI and does not access NAS or private media.

## Changes

- `src/renderer/renderer.ts` now resolves the browser-loaded shared preference module with its `.js` extension.
- `runScan` clears the optimistic running state when the operation rejects, and the `finally` path clears any still-running optimistic state before controls are restored.
- `showPlayer` writes the aria-live current title only when the text changes, so position events do not repeatedly announce the same title.
- `tests/window-smoke.ts` uses the real preference IPC surface and bounded readiness polling instead of fixed startup sleeps.
- `tests/local-library-app-smoke.ts` now launches the real production main/utility worker/IPC/renderer against an owned fixture: one real `assets/test_video.mp4`, one NFO-backed long-title item, and 8,000 zero-byte indexed video/NFO pairs. The single run is bounded by the wrapper's 60-second timeout.
