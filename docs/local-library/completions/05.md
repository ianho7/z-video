## Test-audit/TDD seam decision

The new scale and package checks use the approved owner seams, not private helpers:

- `LocalLibraryDatabase` + real owned filesystem + utility-process SQLite owns scale, concurrent list, and unavailable-source behavior. The independent oracle is the literal fixture count and required public result status; existing metadata/offline tests do not exercise 20,000 rows or query during an active scan.
- Packaged EXE + fresh profile + CDP renderer owns delivery closure and production IPC/SQLite reachability. The independent oracle is the package manifest/resource layout plus `sqliteAvailable`, `ready`, empty page, and path-free DTO returned by the real renderer bridge; this is not a duplicate parser/database unit test.

No test-only production export, mock, path escape hatch, or arbitrary performance SLA was added. The 5-second concurrent-query bound is a smoke safety timeout; recorded timings are measurements, not a product latency promise.
