## Delivered

- Locked `fast-xml-parser@5.11.2` in this worktree's `package.json` and `package-lock.json`. The package is the maintained upstream release, MIT licensed, and is used with entities disabled; NFO never evaluates DOCTYPE/ENTITY or remote references.
- Extended the single utility-process SQLite owner with metadata-safe schema migration: collection identity, movie/show classification, per-file display title/kind, season/episode numbers, artwork source fingerprints/cache keys, and scan generations. Existing schema-v1 rows remain readable.
- Added movie, `tvshow.nfo`, and `episodedetails` mapping, SxxExx/NxM fallback, explicit local artwork precedence, conventional poster/fanart fallback, malformed/oversized NFO warnings, and filename fallback that keeps the video playable.
- Added bounded asynchronous directory scanning with progress events, cancellation, reparse/symlink skipping, selected-root boundary checks, overlap rejection for new roots, incremental identity reuse, and non-destructive missing/offline/cancelled handling.
- Added owner methods `scanFolder`, `cancelScan`, `getPlayback`, `savePlayback` (including the `savePlayback(mediaId, update)` form), and `resolveMedia`; the playback SQL stays behind the worker boundary and uses shared `LocalPlaybackState`/`LocalPlaybackUpdate` types.
- Added main-owned picker IPC for manual scans and cancellation/progress events. Renderer-visible records contain opaque IDs and artwork cache keys only; no private paths or raw URIs are returned.
