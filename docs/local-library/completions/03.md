# Ticket 03 completion: local playback and durable resume

Date: 2026-10-31
Branch: `codex/local-03`

## Delivered

- Added a main-owned local playback coordinator keyed only by opaque `media_<UUID>` IDs. The coordinator resolves the private path through the local-library owner and passes it only to the native libmpv engine.
- Added local playback store contracts for `getPlayback(mediaId)` and `savePlayback(state)`. Progress carries position, duration, selected track IDs, watched state, and `updatedAtMs`; it never carries a path, URI, credential, or NAS context.
- Added fresh-process-compatible restore, observed-position-only persistence, periodic/pause/file-switch/normal-close flushes, and failed-load preservation. Invalid persisted track IDs are ignored after native track enumeration.
- Added local playback IPC/preload contracts and a minimal local-library renderer event/open integration. Default `main.ts` creates only the local database and local playback host; it does not create a NAS session, NAS client workflow, or old `MainPlaybackHost`.
- Kept SQLite worker/database/schema ownership with Ticket 02; the playback host consumes the coordinated DB-owner methods without opening SQLite.
