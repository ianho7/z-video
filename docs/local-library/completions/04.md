## Delivered

- Extended the local-library owner query contract with full-index text search, movie/show/episode/unclassified filters, source scope, title/year/score/recent/added sorting, and bounded pagination. Queries run in the utility-process SQLite owner, not against a renderer-loaded page.
- Added collection detail projection for movie and TV collections, including season/episode records, collection title/kind, metadata and offline availability. Existing `mediaId` remains the only renderer-to-main playback target.
- Added local Continue Watching projection from `playback_state`, preserving opaque IDs and progress only; no NAS/session or path data is returned.
- Added source selection, source refresh, cancellable scan feedback, partial/unavailable status, and explicit source removal. Removal deletes only application database rows and leaves source files untouched.
- Added main-owned artwork resolution and a bounded local thumbnail cache: 512 MiB disk budget, 32 MiB memory hot cache, four concurrent reads, LRU eviction, and native-image downscaling for large derivatives. Renderer gets only data URLs; source paths remain main/worker-only.
- Replaced the foundation renderer with local-library browse/detail UI: fixed-ratio placeholders, visible/detail-priority artwork loading, bounded image concurrency, full-index search/filter/sort/page controls, continue-watching cards, episode selection, offline labels and source actions. Existing main-owned local playback host/IPC was retained.

## Limits / not proved

- Owned fixtures and isolated window checks do not prove practical compatibility with personal media, UNC/share policy, macOS, packaged resources, hardware decode, DWM pixels, or a real native playback sample. Ticket 03's independent native fresh-process proof is in `completions/03.md`.
- Artwork downscaling uses Electron `nativeImage` when the bytes are decodable; malformed or unsupported artwork remains a placeholder and is not a scan failure. No image-probe gate, video probing, or eager full-library thumbnail generation was added.
- Source refresh and removal are application operations only. No source files, NFO, artwork, NAS session, credentials, or old encrypted state are modified.
- The legacy `npm test` NAS fixture suite was not repeated for this ticket; prior environment attribution remains in completions 01/02/03 and is outside this local-library owner proof.
