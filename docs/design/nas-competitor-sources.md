## 用户反馈与性能边界

飞牛社区一位用户于2026-06-22反馈：接近片尾的条目仍占继续观看，手动标记后排序仍不符合追剧预期；管理员回复记录评估。它提示续播状态与排序比海报美观更影响效率，但单帖不是普遍故障或当前版本复现。[原帖](https://club.fnnas.com/forum.php?mod=viewthread&tid=66197)

上述资料没有可比较的启动、滚动或图片性能数据。厂商“流畅”等宣传不能作为性能证据。当前可提出的设计判断是：优先恢复进度/筛选/滚动位置，加载与失败独立显示，维护任务退到二级；具体加载批次、缓存与渲染策略仍需客户端测试。NAS慢、图片慢、UI主线程阻塞与解码播放问题不能混称为卡顿。

## 保留未知

极影视第三方接口能否获取/写回续播与收藏、分页及筛选排序的服务端支持、图片尺寸/缓存头、播放流与硬解路径尚未由此次公开研究证明。官方演示不能证明本客户端拥有这些能力。研究只支撑产品讨论，不授权进入原型或正式 UI 实现。
