## What to build

在海报异步加载、失败和连续滚动期间，卡片不跳动、窗口可操作，用户能区分已加载条目与NAS分类总数。

## Acceptance criteria

- [ ] 未加载、成功与失败封面占位尺寸相同，异步替换不改变标题/卡片位置；失败显示合理占位。
- [ ] 复用现有缓存与过期请求机制；换分类、离页后旧任务不会覆盖当前片库，不为样式重做缓存框架。
- [ ] 用代表性条目数实际滚动、切分类，记录图片任务、响应和资源基线；按测得瓶颈选择分批/可见区域加载，不承诺无数据的提升比例。
- [ ] 已加载数与服务端总数分开；仅有50条时明确范围，不能当全库。无总数时不编造。
- [ ] 提交脱敏Windows操作/渲染证据；仅在图片/模型契约改变时扩展既有Media library行为测试，不重复源码断言。
