## What to build

从Collection进入同窗口独立详情，按已确认原型查看封面、片名、元信息、播放入口、Episode与简介，并可返回片库。

## Acceptance criteria

- [ ] 详情替换主内容，保留侧栏/工具栏；不展开右侧抽屉，不挤压原列表。
- [ ] 优先级、尺寸关系与信息密度对照HTML；长标题、长简介、多季/多Episode、缺封面/缺元数据均可读，不造值。
- [ ] 选集、播放入口、加载/错误反馈和返回接既有协调器；有效历史才展示续播状态，历史链路由T8交付。
- [ ] 鼠标与Tab/激活操作可用；不同窗口尺寸及100%/150%缩放无遮挡，提交脱敏原生详情截图。
- [ ] 复用现有详情导航测试证明Collection/Episode归属与返回；搜索/筛选/滚动恢复由T9负责，不在此复制其测试。
