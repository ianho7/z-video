## What to build

侧边栏和工具栏呈现经真实后端验证的克制磨砂；减少透明度或高对比模式下仍清晰可用。若无法合理还原，用户可依据原生对照决定替代方案。

## Acceptance criteria

- [ ] 核对实际Slint版本、Windows后端和可用效果；使用有背景内容的原生窗口证明模糊，不能把透明颜色当磨砂。
- [ ] 磨砂仅用于侧栏/工具栏，海报、继续观看卡片和详情内容保持实色，避免层叠模糊。
- [ ] 对比原型/原生效果并记录滚动/资源成本；无证据不加平台依赖或承诺视觉已等价。
- [ ] 不支持效果、减少透明度和高对比情境有可读的不透明回退，控件边界与焦点仍清晰。
- [ ] 如无法还原或成本不可接受，提交不透明/半透明替代截图、原因和取舍，得到用户确认后定稿；此确认前不宣称视觉验收完成。
