## What to build

从有证据的真实观看历史显示紧凑16:9横向继续观看条目，点击进入正确Collection/Episode详情，再经既有Playback session续播到正确位置。

## Acceptance criteria

- [ ] 调查并接入有证据的历史来源，不逐条预取全库详情凑首屏，不伪造历史、进度和时长。
- [ ] 横向16:9缩略图加右侧标题、进度/时长，控制高度/间距，匹配已确认原型；无历史合理隐藏/空态，获取失败可重试。
- [ ] 点击条目定位正确Collection与Episode；只在有效历史时提供续播。有效时长才算百分比，否则显示已看时间。
- [ ] 续播复用既有播放协调与进度机制，旧Session结果不污染当前Episode；区分请求、实际开始与NAS保存。
- [ ] 独立脱敏fixture覆盖不同Episode、缺时长/无历史/失败；复用已有播放证据，不靠mock宣称真实NAS持久化；提交原生卡片到详情/续播操作证据。
