## What to build

从搜索/筛选/排序后的片库进入详情，再通过返回或Esc回到原来的查询、滚动位置与键盘焦点，接着选片而无需整库重载。

## Acceptance criteria

- [ ] 保存并恢复来源分类、查询、类型筛选、排序、滚动和打开的Collection焦点；点击返回与Esc行为一致。
- [ ] 返回不无条件重拉整片库、不重置浏览位置；必要刷新保留上下文，过期异步结果不覆盖当前页面。
- [ ] 来源项因数据改变消失时使用合理邻近项/内容区焦点回退，不跳到不存在对象或恢复错误查询。
- [ ] 扩展既有详情导航测试，覆盖带查询/筛选来源进入详情、返回和快速切换，期望来自独立fixture；不只断言条目数。
- [ ] 实际Windows窗口演示滚动→开详情→返回，核对位置、焦点及快捷键。复用仍匹配的视觉证据；最终结合海报墙和暗色外壳验收，不要求重跑无关播放协议。
