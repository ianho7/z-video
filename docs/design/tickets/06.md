## What to build

搜索实际改变Collection结果，可清空返回浏览，并明确查询范围；加载、无结果与失败可区分，快速改词不会被旧响应覆盖。

## Acceptance criteria

- [ ] 先复用已有逆向/协议记录核对搜索能力，必要时只读脱敏验证；明确静态候选与运行时证据，不猜全库API。
- [ ] 按已证明的数据范围接通UI输入→Rust查询→结果/计数/状态；若仅查已加载条目明确标注，不能用50条冒充全库。
- [ ] 输入立即反馈，后台查询防抖，Enter立即提交；清空恢复浏览；慢旧查询失效，失败可重试，不静默空列表。
- [ ] Ctrl/Cmd+K可聚焦搜索；无能力时明确不可用/范围及恢复路径，不再仅写隐藏状态文本。
- [ ] 扩展既有协调器入口，以独立脱敏fixture覆盖乱序、清空、空结果/错误和范围；实际原生窗口演示输入到结果，不新增测试专用生产接口。
