## What to build

在同一查询状态下组合类型筛选、排序与清除条件，结果、计数和空状态反映声明的数据范围，未知能力明确呈现。

## Acceptance criteria

- [ ] 核对分类/筛选/排序/分页证据，服务端全库能力与已加载集合内操作明确区分，不伪装全量排序。
- [ ] 筛选、排序与搜索组合后结果正确；清除条件恢复明确默认状态，过期结果不覆盖新条件。
- [ ] 所有入口基于真实数据契约；收藏等未确认能力明确不可用或隐藏，不构造假集合。
- [ ] UI选择状态、加载/无结果/失败和结果计数一致，鼠标/键盘可操作，原生窗口演示组合查询。
- [ ] 扩展T6协调器行为用例，独立fixture验证组合条件和范围，不在多个内部层重复证明；有协议变更时只补其独立边界证据。
