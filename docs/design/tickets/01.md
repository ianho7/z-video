## What to build

在真实 Windows 片库中稳定浏览、用鼠标或键盘打开 Collection；同行等宽，封面始终2:3，窗口变化时合理调整列数，长标题和源图尺寸不再撑开网格。

## Acceptance criteria

- [ ] 用横图、竖图、超宽图、长标题的同一组脱敏数据重现旧版问题，并提交修复前后原生渲染对照。
- [ ] 同行卡片等宽；封面框2:3，居中按比例裁切，无拉伸；标题省略不改变列宽；视觉层级、间距参考已确认HTML。
- [ ] 在900×640、1440×900、2560×1380下检查合理列数、无水平溢出/重叠；1440基准约7列，不强制所有窗口7列。
- [ ] 卡片焦点可见，键盘激活与整卡点击进入正确Collection详情；保留既有NAS/播放回调。
- [ ] 编译与定向行为检查通过，并实际查看脱敏Windows渲染；记录内容区尺寸、DPI和命令。
