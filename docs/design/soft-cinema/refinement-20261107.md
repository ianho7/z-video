# Soft Cinema · D2 还原与动效执行清单

状态：执行清单；具体动效时长是实现建议，不代表用户已逐项确认。用户要求新增 UI 先提供设计稿并确认；现有预览 `designs/d2-refinement/index.html` 的来源、扫描、首次启动方向已获认可，首页横幅选择方案 01。最终播放叠层和动效细节仍需按用户反馈核对。用户明确不需要“减少动态效果”设置，不新增该设置。

## 分项与验收

1. **海报与首页（先行）**：`views/all.ts`、`views/home.ts`、`renderer.ts`、`styles.css`。海报缺失、加载中、成功和失败时保持由同一 mediaId 决定的容器圆角，大角不能在图片出现后消失。首页按方案 01：左侧内容、右侧保持 2:3 竖海报，不用低清竖图铺满横幅；无海报或解码失败显示生成封面；异步切换不得串图或串色。验收：窗口中检查有图、无图、失败和快速切换；不同宽高比的素材完整显示。已有未提交实现和窗口证据需复核，不预设完成。

2. **自绘窗口栏**：`main/window.ts`、preload、共享契约、renderer。移除系统菜单和原生标题栏，用与 D2 软形一致的最小化、最大化/还原、关闭按钮；支持拖动、键盘和无障碍名称，关闭沿用播放进度保存生命周期。验收：Windows 实窗逐项操作、恢复和关闭；与播放、全屏和窗口尺寸同步共存。跨平台及混合 DPI 分别记录，不推断通过。

3. **播放器和覆盖层（依赖窗口栏）**：对照原型 D2 播放器、菜单和播完接下一集；检查 `renderer/index.html`、`renderer.ts`、`styles.css`、`main/native-window.ts` 和 playback owner。播放态按钮显示暂停图标并执行暂停，暂停态反之；无下一集时整个按钮不显示，存在下一集时动作正确；箭头控件使用 SVG 图标而非文字箭头。进度条包含已播放波浪、未播放直线、可拖动滑块与可读时间，键盘 seek、音量、字幕、倍速和原有快捷键不回归。D2 控件应叠在真实原生视频画面上：现有 Win32 子窗口遮挡 renderer，需先证明覆盖层的层级、输入、焦点、DPI、全屏及关闭生命周期；单纯将控件移到视频外不算叠层通过。真实视频或隔离 fixture 实窗验证，不以 DOM 截图证明 DWM 叠层。

4. **全屏显隐与动效（依赖播放器）**：全屏播放时，用户无操作约 3 秒后控制层以淡出和轻微位移动画消失；鼠标或键盘操作后以对应动画出现。暂停、设置菜单打开、控件获得键盘焦点、拖动进度时保持显示；退出全屏、关闭播放器、切换媒体时清理计时器，不能遗留隐藏控件。建议显现约 180 ms、隐藏约 240 ms，采用柔和缓出，须在设计稿明确演示并经用户确认最终观感。验收：实窗覆盖播放、暂停、焦点/菜单、键鼠唤醒、拖动和退出；检查控件不可见时不会误拦截输入。

5. **全 App 动效与 D2 页面收口**：先在设计稿展示触发位置与效果并取得用户确认，再实施。建议卡片 hover/焦点轻微抬升或圆角变化约 180 ms，按钮按下轻缩放约 100 ms，页面/弹层进入轻淡入约 180–220 ms；不添加持续循环装饰或妨碍浏览的延迟。对照 Home、AllMedia、Sources、ScanPanel、Onboarding、Detail、MovieDetail、States 各 D2 画板，记录并修正用户已认可的视觉层级；扫描只显示 DTO 实有计数，不编造总数或上次扫描时间。验收：可逐项指出触发方式，鼠标和键盘均可操作，状态/错误/离线与原有功能不回归。
