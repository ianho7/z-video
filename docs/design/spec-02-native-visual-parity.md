## Problem Statement

原生界面只近似复用了黑色背景，未保留已确认原型的桌面层级。工具栏出现高大的灰色“隐藏侧栏”按钮和白色搜索框；详情布局、组件状态、文字层级与原型存在明显差异。半透明矩形被当成磨砂替代，却未得到用户对视觉差异的确认。上一轮仅凭编译结果交付，缺少真实渲染验收。

## Solution

统一原生侧边栏、工具栏、搜索控件和详情页的暗色视觉与交互状态，让 Library/Search/Detail 与已确认 HTML 原型具有一致的布局关系和信息密度。真实模糊若受 Slint 或平台限制，先提交可见对照与替代方案，经用户确认后定稿。

## User Stories

1. As a 桌面用户, I want 工具栏高度和控件对齐统一, so that 主内容有稳定起点。
2. As a 用户, I want 搜索框融入暗色界面, so that 不出现刺眼白块。
3. As a 用户, I want 侧栏按钮简洁紧凑, so that 导航不占据过多空间。
4. As a 用户, I want 文字有清楚主次层级, so that 能快速定位标题与信息。
5. As a 用户, I want 详情替换主内容区, so that 海报墙不被右侧面板挤压。
6. As a 用户, I want 详情优先展示封面、片名和播放操作, so that 选片到播放连续。
7. As a 用户, I want 有进度时才显示续播信息, so that 不会看到虚构状态。
8. As a 键盘用户, I want Tab、焦点和激活行为清晰, so that 定制外观不损害操作能力。
9. As a 用户, I want 悬停、按下和禁用状态统一, so that 反馈可预测。
10. As a 用户, I want 功能层的磨砂保持克制, so that 内容清晰且滚动稳定。
11. As a 用户, I want 减少透明度或高对比设置下仍可读, so that 材质不会妨碍访问。
12. As a Windows 用户, I want 缩放后标题和操作不被截断, so that 常见显示设置下能正常使用。

## Implementation Decisions

- 提炼统一 Theme token 与实际复用的控件；不复制一套脱离业务的窗口，不引入 WebView，不修改 NAS/Player 契约。
- 保留默认黑色、单一蓝色强调；统一字体、间距、边界、圆角以及选择/焦点状态。复用或定制控件必须同时满足键盘与可访问语义，不能只绘制按钮外观。
- 工具栏保留上下文、侧栏切换、搜索及必要动作；侧栏以真实 NAS 分类为依据，不伪造原型分类和数量。
- 详情采用独立主内容页，封面、标题/元信息、主操作、Episode 和简介遵循已确认原型的优先级。缺失元数据不造值。
- 磨砂仅限侧边栏和工具栏。先用锁定版本与真实 Windows 渲染后端验证应用内背景模糊；透明颜色本身不是模糊证据。不能保持效果时，展示不透明/半透明替代的截图和成本，取得用户确认；不默认添加平台特效依赖。
- 阅读并更新过时映射记录：Cargo 声明最低 Slint 版本为 1.9.2，但当前锁文件实际为 1.18.1；仓库已有 Cargo、Slint、鉴权和播放实现。文档必须与当前代码/证据一致。
- 已有旧视图与新外壳存在重叠，完成替换后只保留仍被产品使用的路径；清理仅限本次替换，不顺带重构播放器或登录。

## Testing Decisions

- 主证明为同一套脱敏数据在真实 Windows Slint 窗口的 Library/Search/Detail 渲染，对照 HTML；基准 1440×900，补查900×640、2560×1380及100%/150%缩放。记录客户端内容区与窗口装饰差异，避免把不同 DPI 截图当布局回归。
- 检查白色默认控件问题消失、工具栏不再被控件撑高、无裁切/覆盖、详情层级与返回位置正确，并操作侧栏切换、Tab焦点及按钮状态。
- 原型和原生并排展示材质差异；没有真实背景模糊证据，不标注“磨砂已还原”。透明度回退与高对比检查归此 issue 负责，不在网格 issue 重复。
- 复用应用协调器已有 UI 初始化/全屏与详情导航入口；它们仅证明状态与回调，不能替代外观证据。无需新增锁定组件树、颜色源码或内部函数调用的测试。
- 编译及定向行为检查通过后必须看真实渲染，再报告完成；环境阻塞应明确记录。

## Out of Scope

重设计 HTML、营销风界面、macOS 红黄绿装饰、播放器控制层重做、登录重做、主题设置系统、NAS 协议重构和跨平台已支持声明。

## Ticket #9 Skia candidate（2026-10-19）

真实 Windows 候选已使用 Slint git rev `0ade85bfd0a88b6de2f87f767420975f98c141d0` 和 Rust `1.99.1` 构建；PR #13821 的 merge commit 是 `e492aa7`。Windows 显式选择 `backend-winit + renderer-skia`，并保留 `accessibility`。默认状态与 `Z_VIDEO_REDUCED_TRANSPARENCY=1` opaque fallback 在同一 1440x900 logical、125% scale fixture 中均生成了 1800x1125 PNG，DPI 通过 `GetDpiForWindow=120` 记录。

材质边界保持为侧栏和工具栏；海报网格、卡片、详情与视频保持锐利。fallback 使用不透明 surface 并将 blur 设为 `0px`。非 Windows renderer、软件 Skia、真实视频帧和性能仍未验证；不能把 Windows 截图扩展为跨平台结论。详细命令、截图和回滚方式见 `docs/design/evidence/ticket-09/README.md`。
