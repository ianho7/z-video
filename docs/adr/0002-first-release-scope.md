# 首版采用局域网、NAS 现有片库和 Windows 优先交付

状态：accepted；2026-10-16。用户逐项确认首版聚焦 LAN，沿用 NAS 片库并同步观看进度，保证基础播放能力，Windows 先交付，先个人自用验证。GUI 与业务语言沿用 ADR-0001。

选择这一路线，是为了将工作集中在独立连接、片库体验与 Slint 原生播放集成。远程穿透会增加传输与鉴权复杂性；独立媒体库会增加扫描、索引及数据同步；Win/mac 同时交付会提前增加平台集成工作。因此暂缓这些范围，同时将连接方式和平台相关代码集中，保留后续扩展空间。

播放基线为常用素材硬解、拖动、续播、选集、音轨切换、内外字幕及全屏；暂不承诺 HDR、杜比视界与音频直通。具体格式和硬件覆盖依据运行证据记录，不能仅凭播放器宣传认定通过。

未来刮削结果先供预览与人工确认，NAS 写回单独设计。插件只预留契约。公开分发前再确定开源/闭源、签名、更新和许可证方案，依赖选择时保留实际构建与许可信息。

这份记录固定产品范围，不证明独立登录、播放引擎或跨端集成已完成；实施边界以 [架构说明](../architecture.md) 为准。
