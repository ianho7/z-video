# 04: B3a · 首次扫描可见

**What to build:** 用户第一次点“添加文件夹”后，能立刻看到正在扫描什么、已经扫描/加入多少、可以取消；欢迎卡一直保留到第一条内容出现；扫描完成后看到新增/更新/警告摘要，不会马上被“已索引 N 项”覆盖。扫描中的列表不再反复闪骨架。

**Blocked by:** None (can start immediately; coordinate shared local-library/renderer edits with 02)

**Status:** ready-for-agent

- [ ] 扫描状态在顶栏胶囊和首页扫描卡同时可见，默认 1040 窗口不隐藏。
- [ ] 首页显示当前文件夹（安全线索）、已扫描、已加入、耗时/活动状态；没有可靠总数时不显示假百分比。
- [ ] 首页和顶栏都能取消扫描；取消后保留已有索引和播放进度。
- [ ] 欢迎卡与扫描卡共存，直到第一条内容出现才收起。
- [ ] 完成摘要进入应用级 notice，主动关闭前保留；列表刷新和总数不覆盖它。
- [ ] 扫描中只首次加载用骨架，后续刷新原地更新，不每 350ms 替换整页卡片。
- [ ] app smoke 覆盖首次扫描、取消、完成摘要和 1040/900 布局。
