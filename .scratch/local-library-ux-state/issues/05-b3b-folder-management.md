# 05: B3b · 文件夹管理

**What to build:** 用户能在“文件夹”页看到每个来源的盘符/上级线索、作品数和集数，区分两个同名文件夹；可以重扫单个文件夹或全部；单个视频导入后能看到说明。移除来源时明确会删除观看记录、不删除源文件，并使用红色 destructive 确认；来源离线时可以区分“暂时断开”和“已删除”。

**Blocked by:** 02 (B1 · 作品级核心), 04 (B3a · 首次扫描可见)

**Status:** ready-for-agent

- [ ] 文件夹页是顶部一级页面，正确高亮；显示安全 `locationHint`、作品数、集数、可用/离线/扫描状态。
- [ ] 同名文件夹可通过盘符与上级线索区分，不显示完整路径。
- [ ] 单卡“重新扫描”、顶部“重新扫描全部”、添加文件夹、添加单个视频可用；单个视频说明会登记所在文件夹、重扫会影响整个文件夹。
- [ ] 移除对话框写明移除 N 部作品、M 集、删除观看进度、不删除源文件；确认按钮 destructive，取消默认焦点，Esc 可取消。
- [ ] 移除失败留在对话框内，可重试或取消；成功后列表与片库同步刷新。
- [ ] 来源不可用时询问“暂时断开 / 已删除”；暂时保留记录，确认已删除才清理。
- [ ] app smoke 覆盖文件夹页、移除文案、失败重试和离线选择。
