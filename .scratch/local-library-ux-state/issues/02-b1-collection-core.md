# 02: B1 · 作品级核心

**What to build:** 用户打开“剧集”筛选时，每部剧只出现一张作品卡，而不是每一集一张卡；卡片显示剧名、年份、总集数、已看集数和继续观看的季/集；点击后进入该剧的详情，默认选中续播集或第一集未看。电影保持一卡一片，“单集”仍能看到文件级列表。

**Blocked by:** 01 (B0 · 最近发布日期)

**Status:** ready-for-agent

- [ ] 新增作品级读取路径：按 Collection 聚合集数、已看数、可用数、续播和代表集，分页有界，不把整库加载到 renderer。
- [ ] 作品 DTO 只含安全字段；代表 media ID、封面 media ID、续播信息可用，不包含绝对/相对私有路径。
- [ ] “剧集”筛选每个 Collection 一张卡；同一部剧不会因集数重复出现。
- [ ] 点击作品卡打开详情，标题使用 Collection 标题；默认集符合“续播集 → 第一集未看 → 第一集”。
- [ ] “单集”筛选仍返回文件级结果，现有播放路径不回归。
- [ ] 作品计数显示“N 部作品”，不是文件总数。
- [ ] facade 测试覆盖聚合、续播、计数与空/离线；production app smoke 覆盖“剧集”一张卡、打开详情和单集视图。
