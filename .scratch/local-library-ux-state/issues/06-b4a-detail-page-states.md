# 06: B4a · 详情页收口

**What to build:** 用户打开详情时，长片名可以完整阅读；剧集每一集都有自己的已看/进度/未看状态；加载和读取失败有本页状态；来源离线时文案和禁用按钮一致；返回时回到来路（首页、作品列表、单集列表、搜索）并恢复位置。

**Blocked by:** 02 (B1 · 作品级核心)

**Status:** ready-for-agent

- [ ] 详情标题自然换行，长片名不被省略号截断；极端长标题仍可读。
- [ ] 剧集详情显示季度、总集数、已看集数、当前集；每集独立显示已看/进度/未看。
- [ ] 加载使用本页骨架，不保留上一部作品的封面/标题/播放按钮；失败清空旧内容，给重试/返回。
- [ ] 离线详情禁用播放与从头播放，附近写原因；不出现“可继续”与灰色按钮矛盾。
- [ ] 主按钮语义正确：继续播放指定集 / 从头播放 / 重新播放；电影不显示选集。
- [ ] 返回按进入来路回到正确页面并恢复滚动/焦点；顶部导航高亮正确。
- [ ] app smoke 覆盖长标题、每集状态、加载/失败、离线和返回。
