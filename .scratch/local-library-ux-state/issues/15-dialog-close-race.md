# 15: 修复移除/离线对话框关闭竞态

**What to build:** 用户按 Esc 关闭移除对话框后立刻重新打开，再点击“移除并删除进度”时，操作仍然有效；如果移除失败，错误留在对话框里，不会被上一次关闭事件的异步回调清掉。离线“已删除”对话框同样不能在新对话框打开后被旧 close 事件重置。

**Blocked by:** 05 (B3b · 文件夹管理)

**Status:** ready-for-agent

- [ ] 对话框 `close` 事件在重新打开后到达时，不得清空新对话框的 `removingSourceId` / `offlineSourceId`、错误文本或按钮状态。
- [ ] 移除失败注入后，对话框保持打开，错误可见，按钮变“重试移除”；重试成功才关闭。
- [ ] 离线清理失败同样保持对话框和错误，不用旧 close 回调覆盖新状态。
- [ ] 新增回归测试：Esc 关闭 → 立即重开 → 注入移除失败 → 错误仍显示；连续快速打开/关闭不丢状态。
- [ ] typecheck、local-library、app smoke、window smoke 通过。
