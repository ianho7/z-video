**What to build:** 首页、全部、电影默认都以作品为单位：电影一卡一片，剧集一剧一卡；筛选、来源、计数、继续观看、最近加入都使用作品级数据。高级用户仍可切到“单集”看文件级列表。

**Blocked by:** 02 (B1 · 作品级核心)

**Status:** ready-for-agent

- [ ] 首页的继续观看、最近加入、作品片架使用 Collection 卡；每部作品在继续观看中最多一条。
- [ ] “全部 / 电影”默认显示作品卡与“共 N 部作品”，不再用文件数冒充作品数。
- [ ] 类型、来源、排序、搜索都作用在作品级；已保存排序偏好仍生效。
- [ ] “最近发布”排序来自 B0 的日期，无日期条目排在最后并显示未知。
- [ ] 单集视图仍可用；切到单集后计数和文件信息正确。
- [ ] 作品卡不显示文件大小；单集行才显示文件大小。
