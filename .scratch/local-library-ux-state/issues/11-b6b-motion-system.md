# 11: B6b · 动效系统

**What to build:** 动效像“剪辑语言”而不是手机 App 动画：默认硬切，只在反馈、状态变化、首页→详情共形转场、扫描过程、片尾叙事五处出现；默认跟随系统“减少动画”，可手动切到更弱或关闭；焦点环永不动画；播放路径不被转场阻塞。

**Blocked by:** 10 (B6a · 原生控件、字体与手感)

**Status:** ready-for-agent

- [ ] 90/140/200/420ms token 与三条缓动落地；返回转场 160ms；进度/倒数只使用 linear。
- [ ] 五个原型按规格实现；全站唯一共享元素过渡是首页→详情；不做逐卡 stagger、波浪流动、水位上涨、饼干旋转或任何 infinite 装饰（扫描活动指示除外）。
- [ ] 默认跟随系统 reduce；产品至少提供“跟随系统”，手动完整/减弱/关可后置；减弱时去位移/缩放/循环但保留颜色/透明度。
- [ ] 焦点环无动画；`prefers-reduced-motion` 下静态等价文案仍在（扫描计数、片尾下一集、已看/进度）。
- [ ] 播放路径转场 ≤200ms 且可跳过；转场中点“继续播放”立即让位。
- [ ] 只能动 `transform`/`opacity`；每视图最多 1 个并发动画；`will-change` 用完即摘。
- [ ] 用真实可见窗口验证动画名、时长和降级；不用隐藏窗口断言 CSS 过渡；截图不替代动效证据。
