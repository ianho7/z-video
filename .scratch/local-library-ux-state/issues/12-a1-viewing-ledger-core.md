# 12: A1 · Ledger 核心

**What to build:** 用户播放当前片库里的文件时，应用自动记录打开次数、有效观看次数、累计实际播放时长、完整看完次数、上次打开时间、上次打开时长；详情显示“你的记录”。删除影片、文件夹或来源时，这些记录一起消失；来源只是离线时保留，扫描确认缺失才清理。

**Blocked by:** 01 (B0), 02 (B1), 11 (B6b · B 完成)

**Status:** ready-for-agent

- [ ] schema v3 新增 `viewing_sessions` 与 `media_history`；不新增全局统计表，不保留跨删除 tombstone。
- [ ] 播放器会话记录实际播放秒数、墙钟、起止位置、完成、关闭原因；暂停不计时，seek 不伪造完成，崩溃恢复为 interrupted。
- [ ] 有效观看 = ≥30 秒且 ≥3%；完成 = ended 或 ≥90% 且有效播放 ≥30 秒；打开与有效观看分开计数。
- [ ] 详情“你的记录”显示打开/有效/累计/看完/上次打开/上次时长/完成率/GB 小时；无记录不显示一堆 0。
- [ ] 删除单文件、删除文件夹、移除来源会显式清理记录；来源离线保留；扫描确认缺失清理；重新加入从新记录开始。
- [ ] 旧 `playback_state` 只作为“上次看到（旧记录）”，不伪造次数/累计时长。
- [ ] facade/app smoke 覆盖会话聚合、删除级联、离线保留、缺失清理、无路径泄漏。
