# 08: B5a · 搜索视图

**What to build:** 用户搜索时进入独立的“搜索「X」”视图，显示数量、当前类型和返回路径；剧名或单集名都能找到作品，只命中单集时在作品卡上标出匹配集；清空搜索回到搜索前的页面；切换顶部导航时旧搜索词不会偷偷生效。

**Blocked by:** 02 (B1 · 作品级核心), 03 (B2 · 首页与片库作品化)

**Status:** ready-for-agent

- [ ] 搜索是独立视图，有标题、数量、筛选和明确返回/清除入口。
- [ ] 搜索匹配 Collection 标题或任一 Episode 标题；同一作品只出现一次，命中单集用 chip 标出。
- [ ] 搜索内切换类型保留 query；清除搜索回到来路，不默认回首页。
- [ ] 切顶部导航（首页/片库/文件夹）清空 query；详情页的搜索入口提交后进入搜索视图，不静默改背后列表。
- [ ] 详情/播放器不出现会静默过滤的全局输入框。
- [ ] app smoke 覆盖剧名/单集名命中、重复作品、清除返回和切导航清 query。
