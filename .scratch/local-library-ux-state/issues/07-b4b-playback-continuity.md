# 07: B4b · 播放连续性

**What to build:** 用户从详情打开播放器，关闭后回到该详情而不是被丢回片库；从首页打开则回首页；片尾提示显示下一集名称和时长，电影只显示重播/返回；播放设置是分组面板，支持关闭、Esc、点外关闭；播放失败在播放器画面内给重试/返回。

**Blocked by:** 06 (B4a · 详情页收口)

**Status:** ready-for-agent

- [ ] 播放器记录打开来路；关闭按钮文案/读屏随来路为“返回详情”或“返回首页”。
- [ ] 从详情关闭回详情并保留选中集与滚动位置；从首页关闭回首页。
- [ ] 片尾显示下一集完整季/集/名称与 10 秒倒计时；立即播放、取消、返回详情可用；电影不显示“返回剧集列表”。
- [ ] 设置面板按播放速度、音轨、字幕、外挂字幕分组；Esc/点外关闭并把焦点还给设置按钮。
- [ ] 播放错误在画面内显示原因与重试/返回，不只写 sr-only 状态。
- [ ] 音轨/字幕/倍速使用应用内菜单，不出现原生 select。
- [ ] app smoke 覆盖两条来路、片尾下一集、电影片尾、设置关闭和播放错误。
