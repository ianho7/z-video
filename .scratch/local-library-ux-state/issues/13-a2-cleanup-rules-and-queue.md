# 13: A2 · 整理规则与队列

**What to build:** 用户从片库进入“整理”，看到当前文件中的删除候选，每条都写明命中的规则、当前阈值和具体数字；可以用保守/标准/积极预设或逐项自定义阈值，开关 A–E 规则，标记保留/稍后/待删，最后汇总成待删清单和总 GB。应用不自动删除任何文件。

**Blocked by:** 12 (A1 · Ledger 核心)

**Status:** ready-for-agent

- [ ] 阈值全部可设置：保护/久未/强久未天数、打开少、有效观看时长+比例、完成、大/很大/超大 GB、一眼/低回报上限、低回报/低回访打开上限、相对大。
- [ ] 三档预设正确写入对应阈值；自定义逐项可改，恢复默认；设置存应用偏好，不写媒体表。
- [ ] 规则 A–E 可独立开关；候选卡显示规则名、当前阈值、打开/观看/大小/上次打开等数字。
- [ ] 排序为 C→D→A→B→E，同规则按可释放空间降序；不生成单一“推荐分”。
- [ ] 保留/稍后/待删可用；稍后默认 30 天，保留默认 180 天；待删清单只统计当前在盘文件与总 GB。
- [ ] 不自动删除；提供“在资源管理器中显示”，移除动作留给用户。
- [ ] app smoke 覆盖预设/自定义变更、候选原因、规则开关、稍后/保留、待删清单和 900×640。
