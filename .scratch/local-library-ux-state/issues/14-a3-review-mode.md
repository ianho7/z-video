# 14: A3 · 检查模式

**What to build:** 用户从整理队列打开一部候选影片时，播放器顶部显示“第 N 次打开 · 累计 X 分钟 · 上次 N 天前”，关闭时可以直接标记“保留 / 待删 / 稍后”，不用回到资源管理器再记一遍；日常从片库打开不出现这条打扰。

**Blocked by:** 13 (A2 · 整理规则与队列)

**Status:** ready-for-agent

- [ ] 只有从整理队列进入时才显示检查叠层；从片库/详情正常播放不显示。
- [ ] 叠层显示准确的打开次数、累计实际播放、上次打开时间；数据来自 A1，不在 renderer 重新计算。
- [ ] 关闭时提供保留/待删/稍后；选择后回到整理队列并更新状态，不自动删除文件。
- [ ] 键盘可完成打开、标记和返回；焦点返回原候选卡。
- [ ] 900×640 下叠层不遮挡播放控制关键动作，不裁切。
- [ ] app smoke 覆盖检查模式来路、标记三种状态、返回队列和正常播放不显示。
