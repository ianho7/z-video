# 09: B5b · 分页与恢复

**What to build:** 大库用户可以首页/末页/跳页，始终看到“第 X / Y 页”；顶栏和筛选保持可达；换页、筛选、排序、搜索回到顶部，从详情返回恢复原滚动位置；空、错、离线状态都有明确的下一步。

**Blocked by:** 03 (B2 · 首页与片库作品化), 06 (B4a · 详情页收口)

**Status:** ready-for-agent

- [ ] 分页包含首页、上一页、页码、下一页、末页、第 X/Y 页和跳页输入；无效页码回有效页。
- [ ] 作品 24/页、单集 24/页；空结果不伪装成加载失败，失败不伪装成空片库。
- [ ] 顶栏保持可见；筛选条在 1040/900 允许的高度内可达，不隐藏关键动作。
- [ ] 900×640 的 compact 扫描胶囊断言先重置滚动到顶部；顶栏应 sticky，不允许依赖测试顺序通过。
- [ ] 换页/筛选/排序/新搜索滚到顶部；详情返回恢复页码、滚动和原卡焦点。
- [ ] 无来源/0 作品/搜索无结果/筛选无结果/加载失败/存储错误/离线都有具体 CTA；错误码进技术详情。
- [ ] 900×640 下分页、空态和错误卡不裁切。
- [ ] app smoke 覆盖跳页、回顶、返回恢复、空/错/离线 CTA。
