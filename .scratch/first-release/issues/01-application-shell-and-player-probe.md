# 01: 基础工程骨架与 Slint 原生播放引擎嵌入探针

**What to build:** 建立客户端的基础应用骨架与桌面窗口，并探通候选播放引擎（优先 libmpv）与 Slint 窗口的底层集成机制。加载本地测试视频文件，验证在 Windows 平台下原生视频可以在 Slint 窗口中正常渲染画面、响应基础暂停/继续操作，确保窗口不黑屏且 UI 交互线程非阻塞。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 初始化应用主工程结构与 Windows 平台构建配置
- [ ] 成功创建 Slint 主窗口，并完成原生播放引擎（libmpv）与 Slint 窗口表面的底层嵌入
- [ ] 能顺利加载并播放本地样本视频，视频画面正常渲染，音频正常输出，无窗口黑屏或无故崩溃
- [ ] 播放期间 UI 线程保持活跃响应，能够通过界面按钮或按键触发播放与暂停操作
- [ ] 记录 Windows 下播放引擎集成依赖版本、构建来源及真实运行表现
