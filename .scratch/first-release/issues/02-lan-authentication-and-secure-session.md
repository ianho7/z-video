# 02: 局域网 NAS 认证与安全凭证管理

**What to build:** 提供用户登录界面，允许输入局域网 NAS 访问地址、账号与密码，并在必要时完成 MFA 短信验证码输入。业务核心独立完成局域网密码加密握手与会话建立，安全存储访问凭证，并在会话失败或网络异常时提供清晰的状态引导与重新登录入口。

**Blocked by:** 01: 基础工程骨架与 Slint 原生播放引擎嵌入探针

**Status:** ready-for-agent

- [x] Slint 界面呈现局域网连接与登录表单（包含地址、账号、密码及验证码输入状态）
- [x] 业务核心独立完成 NAS 鉴权流程（包括密码加密与会话获取），成功建立有效 Session 并过渡到主界面
- [x] 登录成功后将凭据持久化存入系统安全存储（Windows Credential Manager），后续打开可自动读取
- [x] 密码错误、验证码失效、网络超时或未授权等异常场景下，界面显示友好且明确的恢复引导
- [x] 所有业务日志、错误跟踪与控制台输出中绝不打印明文密码与敏感 token
