# 07: 海报缓存容量治理与异常恢复

**What to build:** 为本地海报图片与临时文件设定明确的磁盘容量上限与 LRU（最近最少使用）淘汰机制，确保长期运行不无限膨胀磁盘。强化异常与网络断开处理，页面离开时主动取消失效的网络与解码任务，会话过期时优雅引导重新鉴权。

**Blocked by:** 03: 极影视片库海报墙与分类浏览, 06: 基础播放控制、全屏与硬件解码

**Status:** ready-for-agent

- [ ] 本地海报缓存具备上限容量控制，达到阈值后自动按 LRU 策略清理最旧的非关键缓存
- [ ] 用户快速滚动或切换离开页面时，已排队或过期的海报下载与解码请求被及时取消，释放网络与计算资源
- [ ] 当 NAS 局域网连接断开或 Session 过期失效时，应用不崩溃卡死，并在界面弹窗或横幅提示重新连接
- [ ] 再次审查日志文件，确保在各种网络超时与错误上报分支中，无任何敏感会话 token、密码或私人媒体地址明文泄露
