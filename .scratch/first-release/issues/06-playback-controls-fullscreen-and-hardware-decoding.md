# 06: 基础播放控制、全屏与硬件解码

**What to build:** 为视频播放提供沉浸式 OSD 控制图层（鼠标移动唤出、自动淡出隐藏）。支持播放/暂停、播放时长与剩余时间显示、进度条拖动 Seek，且拖动时不被引擎异步进度回调回弹拉扯。支持进入/退出全屏，并在支持的 Windows 显卡硬件上启用硬解播放常见编码。

**Blocked by:** 05: 独立局域网媒体流获取与窗口播放打通

**Status:** ready-for-agent

- [ ] 鼠标悬浮或移动时唤出 OSD 控制层，无操作数秒后自动平滑隐藏；控制层点击不穿透误触
- [ ] 支持通过界面按钮或快捷键（如空格键）暂停和继续播放
- [ ] 进度条支持点击与平滑拖动定位（Seek），定位生效前暂停画面同步，定位完成后平稳继续播放，无画面反复回弹
- [ ] 支持在窗口模式与无缝全屏模式间切换，全屏切换期间视频声画不断，控制层与分辨率自适应
- [ ] 在支持的硬件上验证并记录 H.264/HEVC 格式素材的硬件解码状态，记录实际使用的硬解后端
