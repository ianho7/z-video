# 05: 独立局域网媒体流获取与窗口播放打通

**What to build:** 在详情页选定 Episode 后点击“播放”，业务核心向 NAS 请求该剧集在当前局域网下的直连有效媒体流（脱离官方本地代理环境），创建并管理 Playback session，将流无缝传入嵌入在 Slint 窗口中的播放引擎，展示加载缓冲状态并完成真实声画播放。

**Blocked by:** 01: 基础工程骨架与 Slint 原生播放引擎嵌入探针, 04: 影视详情展示与剧集选择

**Status:** ready-for-agent

- [ ] 在详情页点击目标 Episode 的播放按钮，界面过渡至全屏/主窗口视频播放视图
- [ ] 业务核心独立解析并获取 NAS 局域网媒体流直链，并在请求中携带合法会话凭证
- [ ] 创建隔离的 Playback session，将媒体流传递给播放引擎，成功输出视频图像与声音
- [ ] 播放前及缓冲阶段展示清晰的加载中等待动画，网络断流或地址失效时给出明确失败提示
- [ ] 退出播放能够完全清理当前 Playback session 与引擎资源，并平稳回到详情页
