# 04: 影视详情展示与剧集选择

**What to build:** 用户在海报墙点击 Collection 进入详情界面，查阅影片封面、背景大图、简介、上映年份、分类标签等元数据。正确展示剧集（Episode）列表（电影单集，电视剧多季多集），支持用户手动查看和选定目标剧集。

**Blocked by:** 03: 极影视片库海报墙与分类浏览

**Status:** ready-for-agent

- [ ] 点击 Collection 平滑导航进入详情页，呈现完整标题、剧情简介、上映年份及分类标签
- [ ] 针对单片（电影）展示单个播放入口；针对多集剧集（电视剧/动漫）按季组织并列出 Episode 清单
- [ ] 用户可清晰切换并高亮选中不同的 Episode，选中状态与剧集元数据准确绑定
- [ ] 支持从详情页返回片库网格，且保持之前的浏览位置与滚动状态
